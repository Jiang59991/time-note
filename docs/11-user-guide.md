# Time Note 使用说明

## 打开与开始

双击 `Time Note.app`。首次打开为空账本，没有示例时间记录。应用不需要联网或登录。

顶部为日览、周览、记录三个页面。右上角菜单与 Mac 菜单栏中的时钟图标可进入设置和数据操作。

- 现在开始：填写事项，选择普通计时或番茄钟，点击开始。可以留空名称，之后修改。
- 补记一段：默认今天，填写开始和结束时刻。历史日期通过“更改日期”展开；跨午夜需要明确选择结束日期或“结束于次日”。
- 补记保存成功后会自动显示记录开始日期的日览；再切到周览时显示同一周。保存失败则保留表单，不切换日期。
- 多项并行：开始新任务不会结束旧任务；每个进行中事项有自己的结束按钮。
- 番茄：长度可设为 1–240 分钟，到期只完成这一轮，不自动开启下一轮。

## 查看和修改

日览只有全天时间色带和 Todo。悬停或键盘聚焦色块查看完整详情，点击进入编辑；重叠色块先选择具体事项。日览中的 Todo 与计时记录独立。跨天后，未完成的 Todo 自动延续到今天；已完成项不带入新一天，仍可切回原日期查看。关闭应用数日后重新打开，也会把过往未完成项延续到今天，不重复创建。未来日期的计划保留在原日期。

周览每天一条时间带，底部按固定顺序展示科研、自媒体、运动、娱乐、睡眠、餐饮、生活、杂事、其他的累计时长。并发事项分别累计，因此它们的总和不一定等于实际经过的时间。

修改记录时可以改名称、分类和起止时间。未提交的表单草稿只在当前窗口内存中，退出应用前请完成保存。正在计时的记录保留空结束时间会继续计时；填写结束时间后保存会结束该项。已经完成的记录不能通过清空结束时间重新变为运行。删除前会确认。

手选分类优先于关键词建议。同名事项的人工分类会被记住，下次录入自动采用；已有历史记录不会被新规则批量改写。

## 关闭、退出与提醒

无边框便签不显示系统红黄绿按钮。按 ⌘H 或菜单中的“隐藏 Time Note”收起便签，应用仍留在菜单栏继续运行；用菜单栏的时钟图标重新打开。

完全退出不会丢失开始时间，也不会自动停止普通计时；下次打开时会恢复。番茄按照原定截止时间结算，休眠或退出期间不会凭空增加新的轮次。

首次使用番茄提醒，请在“设置与数据”中选择“启用番茄完成通知”，并允许 macOS 通知。应用会给每个活动番茄安排独立的系统提醒。系统专注模式、通知权限和休眠状态会影响提醒显示；时间记录仍按实际截止时间保存或在重新打开时结算。

## 便签外观

1.0.1 移除了系统标题栏及红黄绿按钮。按住顶部日期文字或顶部留白即可拖动；日期切换箭头、标签页和设置按钮仍可正常点击。“锁定窗口位置”开启后会禁用拖动。

右上角齿轮 → 窗口设置：

- **窗口置顶**：默认开启，便签在所在桌面的普通应用窗口上方；可取消置顶。
- **仅在当前桌面显示**：默认开启，切换到其他桌面时便签不会跟随；回到原桌面即可看到。关闭此项才会在所有桌面显示，与置顶开关独立。重新启动时，窗口在启动所在桌面打开，不绑定固定的桌面编号。
- **背景不透明度**：拖动 0–100% 滑杆即时调整；0% 为透明背景，100% 为不透明纸色。只调整背景，不降低文字和控件的不透明度。系统毛玻璃底层已移除。
- **锁定窗口位置**：固定便签位置。

这些设置重开后保留。日览、周览和记录页分别记住窗口尺寸，位置也会保存。系统锁屏、安全界面及某些独占全屏应用的层级由 macOS 管理，不承诺覆盖它们。

标准文本框支持 macOS 自带的听写和常规复制粘贴；应用没有独立录音上传服务。

## 数据和备份

实际数据位于：

```
~/Library/Application Support/Time Note/
```

“打开数据文件夹”可以定位它。应用升级、移动或重新复制 `.app` 不会主动清除此目录。只有一个应用实例可以同时写入同一个账本。

在“设置与数据”里：

- 导出完整 JSON 备份：保存可用于恢复的所有记录与 Todo。
- 导出 CSV：用于电子表格分析，时间包含时区。
- 导出 Markdown：用于阅读或放入笔记库。
- 从 JSON 备份恢复：先检查文件，再显示替换确认。确认后替换当前整个账本，不是合并；原有数据会先备份。

每次保存前会在 `Backups/` 保留旧账本，最多保留最近 20 份。导出文件必须保存到此数据目录以外，以防覆盖内部文件。仍建议定期导出完整 JSON，并交由你的常用备份工具保存。不要把运行中的数据文件放进代码仓库或直接同步冲突的多个应用副本。

若遇到文件损坏，应用会报错而不会悄悄创建空账本覆盖它。先退出应用，将整个数据目录复制到另一个安全位置。把损坏的 `store.json` 改名保留，再将可信的完整 JSON 备份复制为原位置的 `store.json`，然后重新打开应用。也可以从 `Backups/` 选取较新的完整备份。不要直接删除损坏文件或唯一备份。

## 分享

分享 `Time-Note-macOS.zip`，接收者解压后将 `Time Note.app` 放进自己的应用程序目录，双击打开。分享应用不会包含你的时间记录。

此版本采用本地 ad-hoc 签名，尚未进行 Apple Developer ID 签名及公证。通过下载获得的副本可能被 Gatekeeper 要求确认来源；不要关闭整个系统的安全检查。可信来源的应用可按 macOS 提供的打开流程处理。

具体实测系统、构建架构与测试结果见发布验证记录。此版不提供 Windows、手机或云同步功能。

## 餐饮分类（1.0.3）

“餐饮”在睡眠与杂事之间单独显示。早餐、午餐、晚餐，以及早饭、午饭、晚饭、吃饭、用餐、夜宵自动建议为餐饮；人工选择和同名事项的人工分类记忆仍优先。新增规则不会批量改写过去的记录。餐饮可单独统计、编辑、备份恢复与导出。

## 视图切换位置（1.0.5）

日览、周览与记录切换时保持窗口右上角不动，尺寸向左、向下展开或收回。若展开会超出屏幕可用区域，会将窗口限制在屏幕内；建议把便签放在屏幕右上方。

## 纵向周览

周一到周日横向排列，时间从上方 0 点向下至 24 点。每三小时一条参考线，色块可悬停查看、点击修改，重叠时仍可选择原记录。默认窗口宽 520、高 740，分类时长在下方分两排显示。切换视图仍固定右上角；首次更新不沿用旧横版周览的宽度，之后记住自行调整的尺寸。

## 多行日览

日览中每项记录独立一行，直接显示标题和时间，下面的 24 小时时间条高 24 点。重叠任务上下对齐，短任务也可点击完整标题编辑。超过可见高度时只滚动时间区域，Todo 保留在下方。默认日览 460×600，切换仍固定右上角。周览继续合并重叠记录。

## 紧凑日览（1.0.8）

日览按开始时间安排时间条，仅重叠任务分到不同行。上一任务结束时开始的任务可复用该行，行数取决于最大同时进行数。色条高 32 点，短任务悬停或键盘聚焦可看完整标题和时间，点击可编辑。默认窗口 460×460。此规则替代上一版每项独占一行。

## 奶油白配色（1.0.9）

背景改为奶油白 #FFFBF0，保持原背景不透明度设置。科研天蓝、自媒体珊瑚粉、运动薄荷绿、娱乐明黄、睡眠浅灰、餐饮杏橙、杂事青绿、其他玫瑰粉；日览、周览和分类统计统一采用新颜色。

## 悬浮小圆球（1.1.0）

默认启动为右上角 40×40 的奶油白时钟圆球，移入约 0.2 秒展开，点击也可展开。鼠标离开窗口及其 8 点缓冲区约 0.9 秒后收起。输入框聚焦、编辑／确认弹窗、设置菜单、系统文件面板、拖动或缩放期间保持展开；结束输入后点击非输入区域即可恢复自动收起。收起保留当前视图和未保存草稿，计时继续。设置菜单中的“移开鼠标后收为小圆球”可以关闭；菜单栏显示窗口命令也能展开。第一次升级定位当前屏幕右上角；以后沿用窗口位置，展开固定右上角。

## 白色与统一色卡（1.1.1）

窗口、弹窗和圆球背景为白色。任务直接选用 Tailwind CSS v3 官方色卡：科研 Blue 200 #BFDBFE、自媒体 Rose 200 #FECDD3、运动 Emerald 200 #A7F3D0、娱乐 Amber 200 #FDE68A、睡眠 Gray 300 #D1D5DB、餐饮 Orange 200 #FED7AA、杂事 Teal 200 #99F6E4、其他 Violet 200 #DDD6FE。文字和网格使用中性灰。色卡来源：https://v3.tailwindcss.com/docs/customizing-colors 。此配色替代旧奶油白方案；透明度设置保留。

## 时间输入与黄色圆球（1.1.2）

开始／结束时间支持连续输入：小时两位后选中分钟，只填小时则分钟默认 00。可点击选择片段、左右方向键切换、粘贴 HH:mm；空白时间仍需填写，非法时刻会拒绝。输入框使用浅灰底色无描边，聚焦仅以下划线提示。圆球为明黄色双竖线眼睛，窗口移除阴影外边，无外框。

时间未填写时显示浅色数字提示 00:00；输入小时后分钟默认 00，空白提示本身不提交为真实记录时间。

## 小黄球拖动（1.1.4）

按住小黄球拖动即可移动；拖动时不展开，松开仍保持小球。鼠标离开再移入可重新悬停展开，直接点击也可展开。展开位置跟随新位置，屏幕边缘会限制在可见范围。窗口位置锁定开启时不允许拖动。


## 色块边缘（1.1.6）

运行版日览／周览去掉进行中任务的虚线轮廓及重叠色块顶部的点线，重叠仍用分类斜条纹表达。悬停详情、点击编辑与重叠候选选择保持原有行为。此项为正式 App 的样式调整，旧设计原型不变。


## 标题输入修复（1.1.7）

修复悬浮球展开后编辑标题可能只能删除、无法输入文字的问题：收起时由 AppKit 正常释放键盘窗口状态，点击展开后的界面时重新取得键盘焦点。仅悬停展开仍不主动抢走其他应用的输入焦点。中英文标题可以删除、重输并保存，计时和历史数据规则不变。


## 标签管理（1.2.0）

齿轮菜单 → **标签管理**，或在记录／编辑页面的分类旁点击“管理标签”。可以新增标签、修改名称，并从 12 种预设颜色中选择颜色；不需要使用取色画板。默认新增“生活”，原有“杂事”及其历史记录保持原分类。标签名最多 20 字，不能重复，最多 64 个标签。新增标签排在“其他”之前。

删除标签前会提示：原来使用该标签的记录及分类记忆会改为“其他”，不会删除时间记录、停止普通计时或改变起止时刻。兜底标签“其他”不能删除或改名，可以换色。名称和颜色会同步到选择器、色块、周统计和导出文件，JSON 备份包含完整标签配置。旧版 V1 账本和备份会自动补入默认标签；保存了新格式后请用 1.2.0 或更新版本打开。编辑表单如因标签删除产生冲突，会保留草稿并要求重新读取。
